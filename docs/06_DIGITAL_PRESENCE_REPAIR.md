# 06 — Digital-Presence Repair Workstream

This is a documented external workstream. Nothing in this repository automates changes to Facebook, Instagram, or Google Business Profile — those platforms have no API integration in Option 1, and account changes require the owner's own login.

## Current known inconsistencies (discovery snapshot, 2026-07-27)

- Facebook Page shows `Dine-in`, `Curbside pickup`, a pound-sign price indicator, and food-related specialties.
- Instagram/location classification associated with "Chicken Joint".
- Facebook Page shows "Always open".
- Google Maps listing categorizes the property as "Hotel".
- Facebook Page shows approximately 1.7K followers, 8 following, 32 posts, and zero reviews.

None of this is treated as evidence of wrongdoing — it reads as inherited/legacy metadata from a prior business use of the same Page or location record. Record only verified platform history; do not accuse the business of buying followers or misleading customers.

## Page-history audit checklist

Before making changes, capture:

- Page creation date
- Previous Page names
- Username history
- Page merge history
- Managing countries/admins
- Whether the Page previously represented a food business

## Ownership note

All platform changes must be performed by the owner or an admin the owner explicitly authorizes, using accounts the owner controls. The developer may advise on the checklist above but does not obtain platform admin access as part of Option 1 unless separately and explicitly granted.

# 02 — Mission

> Build and operate a truthful, mobile-first website that explains the actual TEN29 property, publishes only approved business claims, converts visitors into structured booking enquiries, reliably notifies the owner, and stores clean data that can support future availability, payment, and Messenger automation without a full rebuild.

## Operating commitments

1. Every public sentence about TEN29 traces back to a claim record with a status.
2. Every enquiry is written to durable storage before any notification is attempted.
3. Every page that could be mistaken for a live booking system explicitly says it is not.
4. Every architectural choice in Option 1 anticipates Option 2 and Option 3 without pre-building their functionality.
